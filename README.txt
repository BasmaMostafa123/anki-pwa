Deploy free on GitHub Pages:
1. Create a GitHub repo, upload all these files to the root.
2. Settings > Pages > Deploy from branch > main / root.
3. Open https://YOURNAME.github.io/REPO/ on your phone, then "Add to Home Screen" (Android Chrome: menu > Install app; iPhone Safari: Share > Add to Home Screen).
To publish an update, change the cache name in sw.js (anki-lite-v1 -> v2).
